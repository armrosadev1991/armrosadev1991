# Hi, I'm António 👋

Senior Data Engineer in Lisbon. I design and build **reliable, scalable data pipelines** on the lakehouse, and I use AI to make them better.

### 🔧 What I do

- Batch and real-time ingestion with Spark, Delta Lake and Structured Streaming
- Lakehouse architecture on **Databricks**: medallion layers, Asset Bundles, CI/CD
- Data governance and access control with Unity Catalog
- Data quality, testing and observability so pipelines can be trusted
- Performance tuning and cost optimisation at scale

### 🤖 AI in my workflow

I use AI to help me build better pipelines, faster:

- Spec-driven development: clear specs first, AI agents help implement them
- Automated AI code review of pipelines in CI
- Faster debugging, refactoring and documentation
